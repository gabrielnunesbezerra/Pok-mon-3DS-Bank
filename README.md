# PK confront

Batalha 1 contra 1 de Pokémon em tempo real numa arena 2D. Projeto de fã, sem fins lucrativos, baseado no Poké Arena 2D. Veja `PLAN.md` para a arquitetura e o escopo.

Sprites: PMD Sprite Repository (SpriteCollab), CC BY-NC 4.0. Pokémon © Nintendo, Creatures e GAME FREAK. Este projeto não tem ligação com elas.

```bash
npm install
npm run fetch-pmd   # baixa os sprites do SpriteCollab
npm run serve       # http://localhost:8080
npm test
```
